# Decision log

One short file per technical decision, numbered in order: `0002-routing-library.md`.
Claude adds one in the same PR whenever it picks a library, pattern or structure.
Tine approves it by approving the PR.

## Template
```markdown
# NNNN Title
**Date:** yyyy-mm-dd  **Status:** proposed | accepted | replaced by NNNN

## Context
What problem needs a decision.

## Decision
What we chose.

## Alternatives
What else was considered and why not.

## Consequences
What this makes easier or harder.
```
